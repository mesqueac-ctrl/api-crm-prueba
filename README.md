# CRM API REST - Prueba Técnica

API RESTful desarrollada con Node.js, Express y TypeScript para la gestión de contactos de un CRM, conectada a una base de datos PostgreSQL aislada mediante Docker Compose.

---

## 🛠️ Tecnologías Utilizadas
* **Backend:** Node.js, Express, TypeScript (`tsx`)
* **Base de Datos:** PostgreSQL
* **Infraestructura:** Docker y Docker Compose
* **Control de Versiones:** Git

---

## 🚀 Requisitos Previos
* Tener instalado [Node.js](https://nodejs.org/) (versión 18 o superior).
* Tener instalado y abierto [Docker Desktop](https://www.docker.com/).
